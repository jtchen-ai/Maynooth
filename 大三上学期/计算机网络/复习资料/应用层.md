# 应用层



## **TCP / IP Transmission Control Protocol/Internet Protocol.**

- 计算机系统在网络上通信时会使用一些层，对于 TCP / IP，主要有4层：

  - 应用层 Application layer 

  - 传输层 Transport layer

  - 网络层 Network layer

  - 链路层 Link layer

  - 物理层 Physical layer（有些书说是5层）



## **网络应用架构**

- **客户端-服务器架构**

  - 服务器：有一个始终在线的主机称为服务器，有一个永久且固定的 IP 地址

  - 客户端：请求服务器服务的主机称为客户端，可能有动态 IP，不能和其他客户端直接
    通信，而是通过IP地址通过服务器进行连接

- **P2P 架构(协议：BitTorrent)**
  - peer-to-peer 让多台主机可以直接通信而不需要服务器的帮助
  - 参与特定文件分发的对等节点称为种子。对等节点可以下载等大小的文件块

**进程间通信（操作系统学过）**

- 同一主机，两个进程通过进程间通信 interprocess comunication相互通信，由操作
  系统定义

- 不同主机，两个进程通过计算机网络交换信息相互通信,他们构成了进程对（例如下载
  文件的客户端和上传文件的服务器通过P2P交换文件）

  - 套接字 Sockets:  进程通过称为套接字的软件接口向网络发送消息，并从网络接收
    消息。（可以想象是客户端/服务器 和 TCP 连接中间的门）

  - 接收进程需要有地址，进程必须具有标识符，标识符包括与主机进程相关的 IP 地
    址（128.119.245.12）和端口号



## **Web 和 HTTP**

http://www.someSchool.edu/someDepartment/p



- 网络有三个组成部分：

  - 统一资源定位器 Uniform Resource Locator（URL）：作为网络资源的系统。

  - 超文本传输协议 Hyper Text Transfer Protocol（HTTP）：规范浏览器与服务器
    之间的通信。

  - 超文本标记语言 Hyper Text Markup Language（HTML）：定义网页的结构、
    组织和内容。

- 当用户请求网页（例如点击超链接）时，浏览器会向服务器发送页面中对象的 HTTP
  请求消息。服务器接收这些请求，并以包含对象的 HTTP 响应消息进行响应。

  - 非持久 Non-persistent HTTP: 最多通过 TCP 连接发送一个对象

  - 持久 HTTP：通过单一 TCP 连接发送多个对象

- RTT(往返时间 round-trip time) 

  - 从客户端到服务器再返回的时间

  - 非持久 HTTP 响应时间 = 2RTT+ 文件传输时间

- 例子

  - **200 OK** 

  - **301 Moved Permanently 永久搬迁**

  - **400 Bad Request**       **糟糕的请求**

  - **404 Not Found**         **未找到**  

  - **505 HTTP Version Not Supported 版本不支持**







## **cookies**

- 网络服务器会向网页浏览器发送特定消息，以便服务器监控用户在特定网站上的活
  动，这些消息被称为 cookie
- 会话Session Cookies 登录邮箱，关闭浏览器失效 / 一定时间后失效（重新登录）
- 永久Permanent Cookies 浏览器保存账号密码
- 第三方 Third-Party Cookies 谷歌地图收集个人信息



## **Email** 三个主要组成部分：

- 用户代理 User agents

  - 允许用户编辑消息。例如Outlook

- 邮件服务器 Mail servers

  - 消息被存放在待发送的消息队列中

- SMTP（简单邮件传输协议 Simple mail transfer protocol）

  - 当邮件服务器发送 / 接受邮件时，它作为 SMTP 客户端 / 服务器

  - SMTP标准短信格式：标题header行(To, From, Subject)+正文Body(ASCII)



## 邮件访问协议 Mail access protocols: 

- POP邮政协议 Post Office Protocol：例如 Microsoft Outlook
- IMAP互联网邮件访问协议 Internet Mail Access Protocol：功能更多，将消息
  存储在服务器中
- HTTP：Gmail、Hotmail、Yahoo等



## **DNS 域名系统（Domain name system）**

主机通过IP 地址来标识：121.7.106.83，而人类用名字：maynoothuniversity.ie

DNS 是一种目录服务，提供网络中主机名称与其 IP 地址之间的映射

1. 浏览器**提取主机名**(www.someschool.edu)
2. 主机名**传递**给客户端的 **DNS** 应用。
3. DNS 客户端向 DNS 服务器发送包含主机名的查询
4. DNS 客户端最终会收到包含主机名 IP 地址的回复
5. 一旦浏览器从 DNS 接收到 IP 地址，就可以发起与 HTTP 服务器的 TCP 连接

## **DNS命名空间(name space)**

- 泛域 generic domains：.com商业 .edu教育 .org非营利组织 .net类似商业 
- 国域 country domains：爱尔兰.ie，中国.cn，印度.in，美国.us，英国.uk
- 逆域 inverse domain：它用于将 IP 地址映射到域名。



## **CDN 内容分发网络(Content Distribution Network)**

CDN 本质上是一组分布在全球各地的服务器，目的是加快网页内容的传输速度。

**套接字编程**

开发者必须决定是TCP还是UDP

- TCP 是面向连接的 connection oriented，提供一个可靠的字节流通道，使数据
  在两个终端系统之间流动（3次握手）
- UDP 是无连接的，能够将独立的数据包从一端系统发送到另一端系统，且没有任
  何传输保证。
